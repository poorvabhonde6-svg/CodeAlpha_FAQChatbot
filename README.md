# NeuroNova AI 🤖

NeuroNova AI is a simple AI chatbot web application built using Flask, HTML, CSS, and JavaScript. It allows users to interact with a chatbot that responds to FAQ-based questions with smart matching using NLP techniques.

The project also includes voice input, speech output, chat history, theme toggle, and a clean interactive UI.

## Features
- FAQ-based chatbot responses  
- Voice input and voice output  
- Light/Dark mode toggle  
- Chat history system  
- Clear chat option  
- WhatsApp share option  
- Smart suggestion buttons  
- Interactive UI design  

## Tech Stack

**Frontend Development:**  
HTML5, CSS3 (Flexbox, Grid, Glassmorphism UI), JavaScript (DOM Manipulation, Event Handling)

**Backend Development:**  
Flask (Python), REST API handling

**Natural Language Processing (NLP):**  
Scikit-learn (TF-IDF Vectorization, Cosine Similarity)

**Web APIs:**  
Web Speech API (Speech Recognition & Text-to-Speech)

**Storage & State Management:**  
LocalStorage (Theme persistence, Chat history management)

## How to Run
1. Install requirements  
   pip install flask pandas scikit-learn  

2. Run the project  
   python app.py  

3. Open browser  
   http://127.0.0.1:5000
